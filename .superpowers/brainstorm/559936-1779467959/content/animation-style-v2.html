Animated chip portrait — which direction?

Each option uses temperature-colored ╔║╚ borders. The difference is how data flow and memory activity are shown inside the portrait.

Option A — DRAM breathing, no particles

DRAM rows (▪▪▪) pulse brighter when bandwidth is high. ░▒▓ = Tensix utilization from power. No particle movement.

DRAM rows breathe

Bandwidth encoded as character brightness. Simplest motion. Border teal→gold→red by ASIC temp.

Pros

  • No flicker/noise
  • Easy to scan at a glance
  • Low impl complexity

Cons

  • No read/write direction
  • Less alive feeling
Option B — Teal reads · Pink writes

∘○· teal = DRAM→Tensix reads   ∘○· pink = Tensix→DRAM writes. Density = power proxy.

Teal reads + pink writes

Particles (· ∘ ○) travel between DRAM rows and Tensix interior. Direction and color encode read vs write. Closest to tensix-viz feel.

Pros

  • Conveys direction
  • Reads vs writes distinct
  • Matches tensix-viz feel

Cons

  • BW is power proxy (not real BW)
  • More visual noise
Option C — Particles + Tensix fill bars

∘· teal reads   ∘· pink writes   ▁▂▃ per-cell fill bars (L1 proxy from power)

Particles + L1 fill bars

Same particles as B, but Tensix cells show ▁▂▃ fill bars instead of ░▒▓ blocks — encoding per-cell activity separately from color. Most information-dense.

Pros

  • Highest info density
  • L1 vs DRAM activity visually separate
  • Faithful to tensix-viz

Cons

  • Most complex
  • No real per-core L1 data — all proxied
